# bgworek.io — Astro Portfolio

Personal portfolio site for me: includes CV/bio, academic publications, and mix of scientific or photography galleries.

Originally tried to build a static only site with just html/css (not even Tailwind), but I ended up just giving in. Oh well.

## Stack

- [Astro](https://astro.build) — static site framework
- [Tailwind CSS](https://tailwindcss.com) — styling
- [Motion](https://motion.dev) — animations
- [PhotoSwipe](https://photoswipe.com) — image lightbox
- [Netlify](https://netlify.com) — hosting + forms
- [Fonts](https://github.com/ahatem/IoskeleyMono) - loskeley Mono
- [Colors](https://coolors.co/0a0a0a-fdb900-9cedec-ff8389) - website colors
